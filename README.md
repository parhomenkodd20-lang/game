# Игровой сервер Nature Walk

Файлы: `server.js`, `package.json`, `index.html` (это игра, она же game.html — сервер сам её раздаёт).

## Запуск на Render (бесплатно, без карты)

1. На github.com создай репозиторий и загрузи в него эти три файла (Add file → Upload files).
2. На render.com: New → Web Service → выбери репозиторий.
   Build Command: `npm install` (или оставь пустым), Start Command: `node server.js`, тариф Free.
3. Когда запустится, откроется адрес `https://что-то.onrender.com`. По нему сразу доступна игра:
   отправь эту ссылку друзьям. Оба/все открывают именно её.
   (Если игру открывать из другого места — добавь к адресу `?server=что-то.onrender.com`
   или впиши адрес в `GAME_SERVER_RAW` в начале сетевой части файла.)

## Сохранение мира (чтобы постройки не пропадали)

На бесплатном Render файлы на диске стираются при каждом перезапуске. Чтобы мир жил дальше:
1. Зарегистрируйся на upstash.com → Create Database (Redis, бесплатный план).
2. В разделе REST API скопируй `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
3. В Render: Environment → добавь эти две переменные → сервер перезапустится.

## Настройки (переменные окружения, необязательно)

- `WORLDS` — названия миров через запятую, по умолчанию `Мир 1,Мир 2,Мир 3`
- `MAX_PLAYERS` — игроков в одном мире, по умолчанию 100
- `DATA_DIR` — куда писать сохранения на диск

## Запуск на своём компьютере или телефоне (Termux)

`node server.js` — слушает порт 8080 (или `PORT`). Игра будет на `http://localhost:8080`.
